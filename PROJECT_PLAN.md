# Real Estate AI Chatbot

## Goal
Build a free AI assistant for a real estate business in Pakistan.

## First Version
- A website chat interface for potential property buyers.
- Answer questions using verified property information.
- Ask qualification questions naturally, one at a time.
- Recommend relevant properties from the available inventory.
- Save qualified leads and conversation summaries for the sales team.
- Support English, Urdu, and Roman Urdu.
- Never invent prices, availability, or payment plans.

## Cost Requirements
- Use free and open-source tools wherever possible.
- Avoid paid APIs and subscriptions.
- Build and test locally before considering deployment.

## Future Plans
- Connect the chatbot to WhatsApp.
- Identify which advertisement or project brought each lead.
- Send qualified leads to the sales team with permission for follow-up.
