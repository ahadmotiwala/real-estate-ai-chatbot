# Real Estate AI Chatbot

A first-stage prototype for a real-estate assistant focused on Karachi property enquiries and lead qualification.

## What works in this prototype

- A responsive chat interface.
- A guided conversation for purpose, budget, preferred area, purchase timeline, and optional consultant follow-up.
- A conversation snapshot showing answers collected during the current browser session.
- A fictional sample inventory file at `data/projects.json`.
- A clear guardrail against inventing prices, payment plans, or availability.

## Important limitations

This is **not yet a production AI bot**. The current conversation replies are rule-based, not generated by an AI model. The chat runs in the browser only; it does not save leads to a server or database, send messages to a salesperson, or connect to WhatsApp. The language selector is a UI placeholder and does not yet translate the conversation. Sample projects are fictional and must be replaced with verified information before showing this to customers.

## Run locally

You need Node.js 18 or newer installed.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

To make a production build:

```bash
npm run build
```
